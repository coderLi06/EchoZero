# EchoZero 真人盲测使用说明

## 怎么测试

1. 找 3 名没有玩过 EchoZero 的同学，分别使用 `BT-01`、`BT-02`、`BT-03` 编号。
2. 测试者从主菜单开始独立操作，观察者不讲解按键、规则或解法。
3. 只有在程序崩溃或输入完全失效时才可以介入，并在记录中说明原因。
4. 开始时计时，测试结束后填写对应的 `BT-xx.md`。
5. 完成 3 人后，将结果填入 `盲测汇总.md`。

## 记录要求

- 不记录姓名、学号、账号等个人信息。
- 尽量记录测试者的原话，不要替对方解释。
- 不需要截图。
- 自动 Smoke Test 不能作为真人盲测数据。
- 如需保留程序日志，可将 `session_summary.txt` 复制到本目录，并改名为 `BT-01-session_summary.txt` 等。
