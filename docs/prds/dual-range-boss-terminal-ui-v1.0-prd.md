# 远近程切换、第三场 Boss 与工业终端 UI - PRD

## 目标

- 让实时战斗在贴身高伤与远距安全之间形成明确取舍。
- 让第三场大 Boss 成为可读、可用 Tactical Mode 处理的高潮，而不是只增加杂兵。
- 将 Action Run 视觉统一为参考图所示的旧工业终端风格，同时保持现有高对比语义和 1280×800 布局。

## 功能规格

### 远近程攻击

- 玩家初始为近战模式，按 `C` 在近战/远程间切换。
- 近战攻击距离 1、基础伤害 2，并保留击退。
- 远程攻击沿当前朝向检查最多 3 格，遇墙停止，命中路径上的第一个敌人。
- 远程伤害为当前近战伤害的 50%，使用整数下取整且最低为 1；远程不击退。
- HUD 常驻显示当前模式、距离和伤害；切换与射击产生可见事件反馈。

### 第三场 Boss

- 相位守卫生命从 7 提升为 12。
- 普通攻击伤害提升为 3，相位爆发伤害提升为 4。
- 新机制“十字相位爆发”：特殊攻击同时锁定玩家当前格及其上下左右相邻格；实时执行和 Tactical Preview 使用相同锁定范围。
- Boss 特殊攻击冷却缩短，所有危险格必须在攻击前可见；不使用不可预知伤害。

### UI 与教程

- 使用 Meowa 生成的工业终端组件板作为材质与配色依据；运行时仍用 pygame 绘制，不依赖网络。
- 主色调整为暗钢、旧黄铜、军绿屏幕与琥珀提示；面板增加双层内嵌边框、铆钉和状态灯。
- Boss 战显示独立 Boss 名称、生命条与机制提示。
- 新手教程增加远近程切换说明，并在模拟 HUD 中展示 `C` 键和两种模式差异。

## 验收标准

- [x] `C` 可稳定切换远近程，切换不会消耗攻击冷却。
- [x] 远程只命中三格内同方向的第一个敌人，墙体与超距目标均不命中。
- [x] 近战/远程伤害满足 2:1，近战击退、远程不击退。
- [x] 第三场 Boss 为 12 HP，普通攻击 3、相位爆发 4。
- [x] 十字相位爆发在实时 Intent 与 Tactical Preview 中显示并按同一目标集合结算。
- [x] HUD、Boss 条和新手教程说明完整，1280×800 无裁切。
- [x] 纯领域、交互、渲染、全量测试与 Action/Showcase 冒烟路径通过。

## 实现验收

- 领域、输入与渲染测试覆盖正常路径及墙体、超距、首敌和多格锁定边界。
- 1280×800 视觉 QA 覆盖近战、远程和第三场 Boss 十字锁定，未见文字、面板裁切或遮挡。
- Meowa 最终组件板已登记，运行界面采用可缩放的 pygame 原生绘制，不引入运行时网络依赖。

## 非目标

- 不增加弹药、换弹、枪械掉落、武器背包或新的命令类型。
- 不改原双关卡 Showcase 的手工关卡数值。
- 不把用户参考图或 Meowa 中间裁片直接放入最终包。
