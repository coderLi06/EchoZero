## 测试规则

- 测试者不接受任何口头教学，从 Main Menu 开始，尽量独立玩到 `DEMO CLEAR`；
- 观察者不提示按钮、解法或机制。仅在程序崩溃、输入完全失效等阻断问题发生时介入，并记录介入原因；
- 不收集姓名、账号等隐私数据。可附上本地 `logs/session_summary.txt`；
- 建议全程计时，并保留测试者的原话，不替测试者解释。
